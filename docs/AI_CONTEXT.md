## 🎯 ЗАДАЧА НА НОВУЮ СЕССИЮ: Этап 3 (Светлый скандинавский UI/UX)

В новой сессии предстоит реализовать **дизайн и верстку публичной части сайта**.

### Рекомендуемые скиллы для загрузки в новой сессии:
* `/taste-skill` — анти-шаблонный светлый премиальный дизайн (уровень Figma/x.ai).
* `/ui-ux-pro-max` — подбор цветов, типографики, микро-интерактивностей и равных отступов.
* `Unslop` (из закладок) — устранение типичных штампов «ИИ-дизайна» (неоновых градиентов, мутного стекла).
* `/frontend-design` — современные адаптивные компоненты на Tailwind CSS.

### Визуальный стиль проекта:
* **Эстетика:** Scandi / Minimalist / Japandi.
* **Цветовая палитра:**
  * Фоновый цвет: мягкий молочный / слоновая кость (`#FAFAF9` / `bg-stone-50`).
  * Текст и заголовки: глубокий хвойный графит (`#1C1917` / `#292524`).
  * Акцентный фирменный цвет: хвойный зеленый (`#2D4A3E` / `emerald-800` / `stone-800`).
  * Теплые природные плашки: древесный беж (`#E7DEC8` / `stone-200`).
* **Ключевые страницы для верстки:**
  1. `resources/views/layouts/app.blade.php` — шапка с логотипом «Nordic Huts», навигация, плашка **«Быстрый вход для преподавателя в 1 клик»**, футер.
  2. `resources/views/home.blade.php` — главная страница (атмосферный Hero, карточки преимуществ глэмпинга, витрина 3 топовых домиков, блок отзывов).
  3. `resources/views/catalog/index.blade.php` — каталог с фильтрацией (категория, вместимость, удобства) и карточками домиков с ценой.
  4. `resources/views/catalog/show.blade.php` — карточка домика с галереей, удобствами и формой бронирования с авторасчетом.
  5. `resources/views/auth/login.blade.php` и `register.blade.php` — аккуратные светлые формы входа и регистрации.
