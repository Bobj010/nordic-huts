# 🌲 Nordic Huts — Эко-глэмпинг & Загородный ретрит

> Индивидуальный проект: веб-сервис онлайн-бронирования загородных домиков на Laravel 11/12.

---

## 🚀 Быстрый старт (Запуск на любом ПК)

### 1. Требования
* PHP `^8.3`
* Composer
* Node.js & npm

### 2. Установка в 3 команды
```bash
# 1. Установка зависимостей
composer install
npm install

# 2. Настройка окружения и миграции базы данных с сидами
cp .env.example .env
php artisan key:generate
php artisan migrate --seed

# 3. Запуск локального сервера
php artisan serve
npm run dev
```

Приложение будет доступно по адресу: `http://127.0.0.1:8000`

## 👥 Роли и тестовые аккаунты (Пароль для всех: `password`)

| Роль | Email | Назначение |
| :--- | :--- | :--- |
| **Администратор** | `admin@nordic.local` | Полный доступ: управление домиками, ценами, удобствами и ролями |
| **Менеджер** | `manager@nordic.local` | Панель бронирований: подтверждение и отклонение заявок |
| **Клиент** | `client@nordic.local` | Гость: выбор домика, оформление брони, личный кабинет |

> 💡 **Для преподавателя:** В шапке сайта предусмотрена панель **«Быстрый вход в 1 клик»**, позволяющая мгновенно переключаться между ролями без ввода логина и пароля.
