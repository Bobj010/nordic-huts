## ⚡ Быстрый запуск в 1 клик (Zero-Config)

### Вариант 1: Запуск на Windows в 1 клик (Рекомендуется для преподавателя)
Просто запустите файл **`run.bat`** двойным кликом:
```cmd
run.bat
```
Скрипт автоматически:
1. Проверит наличие PHP.
2. Создаст `.env` из `.env.example` и сгенерирует ключ `APP_KEY`.
3. Создаст базу данных SQLite и выполнит миграции с сидерами (`migrate:fresh --seed`).
4. Откроет ваш браузер по умолчанию на `http://127.0.0.1:8000`.

*(Никаких Node.js и `npm install` не требуется — стили Tailwind CSS v4 и Alpine.js настроены через быстрый CDN).*

---

### Вариант 2: Ручной запуск через консоль
```bash
# 1. Клонирование и настройка окружения
cp .env.example .env
php artisan key:generate

# 2. Миграции и наполнение базы данных
touch database/database.sqlite
php artisan migrate:fresh --seed

# 3. Запуск веб-сервера
php artisan serve --port=8000
```
Открыть в браузере: `http://127.0.0.1:8000`

## 🏛️ Ключевые архитектурные и технические решения

1. **База данных в 3-й нормальной форме (3NF):**
   * Связь **Many-to-Many** между домиками (`houses`) и справочником удобств (`amenities`) через связующую сводную таблицу `house_amenity`.
   * Контроль целостности на уровне СУБД: `ON DELETE CASCADE` для зависимых заявок и `ON DELETE RESTRICT` для базовых категорий домиков.
2. **Чистая архитектура (Clean Architecture & SOLID):**
   * Контроллеры тонкие (`HomeController`, `HouseController`, `BookingController`, `ManagerController`, `AdminController`).
   * Вся валидация изолирована в `FormRequest` (`BookingStoreRequest`) с русскоязычными сообщениями об ошибках.
   * Бизнес-логика расчета ночей и цен инкапсулирована в модели `Booking`.
3. **Решение проблемы N+1 запросов (Eager Loading):**
   * Все запросы каталога и бронирований загружают связи жадным методом `with(['category', 'amenities'])` — 3 SQL-запроса вместо 15+.
4. **Информационная безопасность (OWASP Top 10):**
   * Полная защита от CSRF (`@csrf`), SQL Injection (Prepared Statements PDO), XSS (`{{ }}` экранирование), Mass Assignment (`$fillable`).
   * Кастомный посредник `RoleMiddleware` с алиасом `'role'`.
   * **Self-Demotion Protection:** защита от случайного самопонижения роли администратора.
5. **Светлая скандинавская дизайн-система (Scandi / Minimalist):**
   * Палитра: глубокий хвойный `#2D4A3E` (WCAG AAA контраст 9.8:1), терракота `#C05621`, теплый камень `#FAFAF9`.
   * Типографика: `Noto Serif` (атмосферные заголовки) + `Plus Jakarta Sans` (четкий интерфейсный гротеск).
   * Использование `tabular-nums` для предотвращения дрожания колонок с числами и датами.
